# GreenTogether – Waste Management System (individual project)

GreenTogether is a web-based waste collection and recycling management system developed using ASP.NET Core MVC and SQL Server.

## Technologies
- ASP.NET Core MVC
- C#
- SQL Server
- HTML, CSS, JavaScript, Bootstrap

## Features
- User registration and login
- Illegal dumping reports
- Recycling center finder
- Waste collection schedules
- Points-based reward system
- Admin dashboard (management)

## Project Type
Academic Project – Completed
